# 🎧 SoundCloud Overlay

Игровой оверлей для SoundCloud в стиле Discord: показывает текущий трек поверх любой игры и позволяет управлять воспроизведением, не сворачивая игру.

---

## Что это такое

**SoundCloud Overlay** — это небольшая программа для Windows, которая создаёт полупрозрачную карточку поверх всех окон (включая полноэкранные игры). На карточке отображается играющий в браузере трек SoundCloud, а кнопки позволяют управлять воспроизведением.

| | |
|---|---|
| 🖥️ Платформа | Windows 10/11 (x64) |
| ⌨️ Горячая клавиша | `Alt+D` — показать/скрыть оверлей |
| 🔊 Управление | play/pause, prev/next, seek, лайк, повтор |
| 🔒 Приватность | всё локально (`127.0.0.1`), никаких серверов |
| 📦 Размер | ~78 МБ (установщик) |

**Как это работает:**
1. **Программа** (Electron) рисует оверлей поверх игр и поднимает локальный мост `ws://127.0.0.1:8765`.
2. **Расширение Chrome** читает из вкладки SoundCloud название трека, обложку, позицию — и шлёт в оверлей каждые ~1.2 с.
3. Нажатия кнопок оверлея уходят обратно в браузер — расширение кликает по плееру SoundCloud за тебя.

Интернет нужен только браузеру (для soundcloud.com). Сам оверлей и мост — полностью локальные.

## Установка

### Шаг 1 — Установи программу

Скачай и запусти **`SoundCloud Overlay-Setup-1.1.0.exe`**.

- Мастер предложит выбрать папку (по умолчанию `%LOCALAPPDATA%\Programs\soundcloud-overlay`).
- Создаются ярлыки: рабочий стол + меню «Пуск».
- Удаление — стандартно, через «Параметры → Приложения».

> ⚠️ Windows может показать «Неизвестный издатель» — это нормально: установщик не подписан сертификатом (подпись стоит ~$200/год). Нажми «Подробнее → Выполнить в любом случае».

### Шаг 2 — Поставь расширение Chrome (один раз)

1. Открой Chrome и перейди на `chrome://extensions`
2. Включи **«Режим разработчика»** (переключатель в правом верхнем углу)
3. Нажми **«Загрузить распакованное расширение»**
4. Выбери папку **`extension`** — она лежит рядом с установленной программой:
   - Если ставил по умолчанию: `C:\Users\<имя>\AppData\Local\Programs\soundcloud-overlay\extension`
   - Если менял путь: `<папка установки>\extension`
5. Готово — расширение появилось в списке как **«SoundCloud Overlay bridge»**

### Шаг 3 — Запусти и наслаждайся

1. Открой **soundcloud.com** и запусти любой трек
2. Запусти **SoundCloud Overlay** (ярлык на рабочем столе)
3. Нажми **`Alt+D`** — карточка появится поверх всего

## Использование

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Alt+D` | Показать / скрыть оверлей |

### Кнопки оверлея

| Кнопка | Действие |
|---|---|
| ⏮ | Предыдущий трек |
| ⏯ | Play / Pause |
| ⏭ | Следующий трек |
| ♡ / ♥ | Лайк / снять лайк |
| ↻ / ↻¹ | Повтор: выкл / все / один |
| Клик по полосе | Перемотка (seek) на позицию клика |

### Что отображается

- Обложка трека (миниатюра из плеера SoundCloud)
- Название и исполнитель
- Прогресс-бар с таймером (позиция / длительность)
- Индикатор громкости (только отображение)
- Строка статуса (подключено / нет соединения)

### Индикатор соединения (точка в шапке)

| Цвет | Значение |
|---|---|
| 🟢 зелёный | расширение подключено, трек играет |
| 🟡 жёлтый | подключено, ждёт данных |
| 🔴 красный | нет соединения с расширением |

## Решение проблем

### Оверлей показывает «no connection»

1. Проверь, что расширение установлено и **включено** в `chrome://extensions`
2. Проверь, что открыта вкладка `soundcloud.com` (не закрыта)
3. Перезапусти программу (оверлей), подожди 3–5 секунд
4. Если не помогло — переоткрой вкладку SoundCloud

### Кнопки не работают

- Убедись, что во вкладке soundcloud.com **не стоит пауза** — кнопки шлют команды «кликнуть play/pause», а не «играть немедленно»
- Проверь, что вкладка SoundCloud не в фоновом режиме с замороженными скриптами (Chrome экономит ресурсы на неактивных вкладках)

### Оверлей не появляется по Alt+D

- Проверь, что программа запущена (процесс `SoundCloud Overlay.exe` в диспетчере задач)
- Возможно, `Alt+D` перехватывает другая программа — попробуй закрыть потенциальные конфликты
- Перезапусти программу

### Port 8765 занят

Если на машине уже что-то слушает порт 8765:
- Закрой конфликтующую программу, либо
- Запусти оверлей с переменной окружения: `set OVERLAY_PORT=8766 && SoundCloud Overlay.exe`
  *(и поправь порт в `extension/background.js` → константа `WS_URL`)*

### «Неизвестный издатель» при установке

Это нормально — программа не имеет цифровой подписи (сертификат код-подписи платный). Нажми «Подробнее → Выполнить в любом случае».

### Протокол (WS на 127.0.0.1:8765)

**Расширение → оверлей** (состояние трека):
```json
{
  "type": "snapshot",
  "data": {
    "title": "Track Name",
    "artist": "Artist",
    "artwork": "https://...jpg",
    "playing": true,
    "position": 63,
    "duration": 184,
    "volume": 0.8,
    "liked": false,
    "repeat": "off"
  }
}
```

**Оверлей → расширение** (команды):
```json
{
  "scope": "overlay_control",
  "type": "cmd",
  "cmd": "next" | "prev" | "playpause" | "seek" | "like" | "repeat",
  "position": 123
}
```

## Известные ограничения

- **Громкость** — только индикатор; SoundCloud не позволяет скриптам менять громкость
- **Очередь** — SoundCloud не отдаёт список следующего трека в DOM, поэтому нет «предстоящих треков»
- **Несколько вкладок SC** — если открыто 2+ вкладки soundcloud.com, данные могут «перемешиваться» (команды идут в первую найденную)
- **Обновление разметки SC** — если SoundCloud поменяет CSS-классы, расширение перестанет читать трек (починится правкой селекторов в `content.js`)

## Сборка из исходников

Если хочешь пересобрать установщик сам:

```bash
cd soundcloud-overlay

# установить зависимости (один раз)
npm install

# собрать установщик NSIS (.exe)
npx electron-builder --win nsis

# или просто распакованную версию (без установщика)
npx electron-builder --dir
```

Результат появится в `dist/`:
- `SoundCloud Overlay-Setup-1.1.0.exe` — установщик
- `win-unpacked/` — портативная версия (запуск без установки)
